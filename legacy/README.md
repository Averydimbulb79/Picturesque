# Legacy snapshot

This folder contains a preserved copy of the previous web entrypoint (`index.html`) as it existed before the web-first/main-branch transition.

**Complete original repository snapshot:** [backup/pre-web-first-main](https://github.com/Averydimbulb79/Picturesque/tree/backup/pre-web-first-main).

The backup branch is the authoritative full-source rollback point, including assets, scripts, and other files that may not be present in this folder. Do not assume `legacy/index.html` alone is a standalone build when it references external files.

Future development is intended to occur on `main`. Do not remove this archive or backup branch without an explicit request.
